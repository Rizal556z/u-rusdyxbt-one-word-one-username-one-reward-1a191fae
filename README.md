Entry for the [make.fun bounty "One Word, One Username, One Reward"](https://make.fun/bounty/u-rusdyxbt-one-word-one-username-one-reward-1a191fae).

## What the program does

`main.py` (pure Python standard library, no network, no model calls)
writes exactly one word to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output/entry.txt`), and prints that same word to stdout.

## The word

**keen-meteor-92-4070** — the account's own make.fun username, one
word and nothing else: keen as a meteor, gone in a flash, still
remembered. 19 characters.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/username-test python3 main.py
cat /tmp/username-test/entry.txt  # keen-meteor-92-4070
```
